# Audit Log: 2026-06-09

Foundational audit pass against The Pragmatic Programmer principles
(orthogonality, DRY, no broken windows, easy to change), plus
security-review and vuln scan. PR: `audit/2026-06-09` → main.

## Shipped in this PR

**Orthogonality (`/coupling`):**
- Verdict: codebase is exemplary. The 6 utility modules (`fs`,
  `format`, `string-scanner`, `sanitize-env`, `config`, `sessions`)
  are documented canonical singletons in CLAUDE.md; their high fan-in
  (`fs.ts` is imported by 19 files, `format.ts` by 14) is by design.
- Zero circular imports. Zero wildcard imports.
- One cross-layer reference: `src/utils/config.ts` imports the
  `MaestroConfig` type from `src/analyzers/types.js`. Types only, no
  runtime dependency. Acceptable.

**DRY (`/drift`):**
- No model IDs, no hardcoded year-bound constants, no em-dash usage,
  no hardcoded URLs. CLI-shape drift surface is small and clean.
- All deps in `package.json` are pinned exact (no `^` or `~`), matching
  the CLAUDE.md domain rule.

**Broken windows (`/zombie`):**
- Removed 1 truly dead export: `success` helper in `src/utils/format.ts`
  (no callers anywhere).
- Downgraded 9 unnecessary exports to module-private. These were used
  only inside their defining file but exported anyway, bloating the
  module's public surface:
  - `generateBadge` in `src/commands/audit.ts`
  - `BugEntry` in `src/commands/bugs.ts`
  - `runChecks` in `src/commands/check.ts`
  - `PYTHON_IMPORT_MAP`, `scanNodeImports`, `getDeclaredDeps`,
    `checkLicenses` in `src/commands/deps-scanner.ts`
  - `generateScannedClaudeMd` in `src/commands/scan.ts`
  - `parseSessionLog` in `src/utils/sessions.ts`
- Zero commented-out blocks. Zero TODOs/FIXMEs/HACKs introduced in
  our own code (existing matches are inside string-pattern detectors).
  Zero empty catches.

**Security (`/security-review`):**
- **Command injection in `src/commands/changelog.ts`:** `getGitLog`
  built a shell command via template string with the user-controlled
  `--since` value. A user passing `--since 'yesterday"; rm -rf $HOME/'`
  could execute arbitrary shell. Replaced `execSync(string)` with
  `execFileSync('git', [...args])` so arguments are passed as separate
  argv entries without shell interpretation. Behavior unchanged for
  legitimate input.
- `copyToClipboard` in `src/utils/fs.ts` already uses `execSync` with a
  fixed per-platform command and passes user text via stdin (`input`
  option). No injection. No change.
- Audited `eval`/`new Function` usages: both matches are inside the
  security-scanner's own pattern detection regex strings. Not real eval
  calls.

**Dependency vulnerability (`/vuln`):**
- `npm audit fix` resolved the one moderate-severity vuln in
  `brace-expansion` (transitive). Zero vulns remaining.
